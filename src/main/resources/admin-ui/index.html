How to use this page
  1. Admin URL is usually left as same origin. Only change it for local debugging against another localhost management endpoint.
  2. Admin token is the value configured for the management API, normally MANAGEMENT_TOKEN or management.authToken.
  3. Enter the token and click Use token. The page stores it only in this browser session and then refreshes protected panels.
  4. Click Clear token before sharing the machine or handing the browser to another operator.
